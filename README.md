# 常翔学園シラバスサイト 運用マニュアル

## フォルダ構成

```
syllabus-site/
├── index.html          ← サイト本体（基本的に編集不要）
├── css/
│   └── style.css       ← デザイン（基本的に編集不要）
├── js/
│   └── app.js          ← 動作ロジック（基本的に編集不要）
├── data/
│   ├── syllabus.json   ← ★シラバスデータ（毎年更新）
│   └── curriculum.json ← ★教育課程・目標データ（変更時に更新）
└── pdf/
    └── （PDFファイルをここに配置）
```

---

## 年度更新の手順

### 1. PDFの差し替え

各先生から提出されたExcelをPDFに変換し、`pdf/` フォルダに配置します。

**命名規則の例**：
```
2026_高1_全コース_国語_現代の国語.pdf
2026_高1_スーパー一貫_数学_数学Ⅰ.pdf
curriculum_jhs.pdf      ← 中学校 教育課程表
curriculum_hs.pdf       ← 高等学校 教育課程表
evaluation_jhs.pdf      ← 中学校 学習評価
evaluation_hs.pdf       ← 高等学校 学習評価
goal_kokugo.pdf         ← 国語 教科の目標
```

### 2. syllabus.json の更新

`data/syllabus.json` を開き、シラバスデータを追加・修正します。

#### 1科目のデータ構造

```json
{
  "id": 1,
  "grade": "高1",
  "courses": "all",
  "subject": "国語",
  "title": "現代の国語",
  "units": 2,
  "sub": { "track": "文理共通", "classes": [] },
  "goals": ["目標1", "目標2", "目標3"],
  "textbook": "教科書名（出版社）",
  "materials": "副教材名",
  "eval": {
    "knowledge": "定期テスト・朝礼テスト",
    "thinking": "グループワーク",
    "attitude": "ルーブリック自己評価"
  },
  "plan": [
    { "term": "1学期", "unit": "単元名", "weeks": 5 }
  ],
  "pdfFile": "2026_高1_全コース_国語_現代の国語.pdf"
}
```

#### courses フィールドの指定方法

| 状況 | 記述方法 | 例 |
|------|----------|-----|
| 全コース共通 | `"all"` | `"courses": "all"` |
| 複数コース共通 | 配列で列挙 | `"courses": ["スーパーコース", "一貫コース"]` |
| 単独コース | 配列で1つ | `"courses": ["スーパーコース"]` |

#### sub フィールドの指定方法

| フィールド | 内容 | 例 |
|-----------|------|-----|
| `track` | 文系・理系・文理共通・空文字 | `"文系"` |
| `classes` | 組番号の配列（「組」は自動付与） | `["1", "2"]` → 「1組」「2組」と表示 |

PDFがない場合は `"pdfFile": ""` とします。

## GitHub Pages での公開方法

1. GitHubアカウントを作成（無料）
2. 新規リポジトリを作成（例：`josho-syllabus`）
3. このフォルダの中身をすべてアップロード
4. リポジトリの Settings → Pages → Source を `main` ブランチに設定
5. しばらくすると `https://（ユーザー名）.github.io/josho-syllabus/` で公開される

### 年度更新時の流れ

1. `data/syllabus.json` を更新
2. `pdf/` フォルダに新PDFを追加
3. GitHubにアップロード（上書き）
4. 自動的にサイトに反映される

## コースの追加・変更

コースを増減する場合は以下の2箇所を編集します。

**① `index.html` のフィルター選択肢**（シラバスページ内）：
```html
<select id="sel-course">
  <option value="">すべて</option>
  <option value="スーパーコース">スーパーコース</option>
  <!-- ここに追加 -->
</select>
```

**② `data/syllabus.json` の courses フィールド**：
新コース名を配列に追加するだけで対応できます。

---

## 困ったとき

- JSONの書き方が正しいか確認：https://jsonlint.com/ に貼り付けてチェック
- サイトが更新されない：ブラウザのキャッシュをクリア（Ctrl+Shift+R）
- GitHubの反映に数分かかることがあります
